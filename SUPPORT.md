# Support

Для вопросов по использованию библиотеки, предложения API и обсуждения архитектуры создайте [GitHub Discussion](https://github.com/blassonad/kodik-api/discussions) либо issue с нужным шаблоном, если Discussions не включены. Для воспроизводимых ошибок используйте bug report и приложите минимальный пример без токенов.

> Не публикуйте рабочие ключи Kodik или других сервисов. Уязвимости и возможные утечки следует отправлять только по процессу из [Security Policy](SECURITY.md), а не в публичном issue.

Поддержка касается Rust-библиотеки этого репозитория. Вопросы о доступе к Kodik API, его токенах, контенте и сервисной инфраструктуре необходимо направлять владельцам Kodik API.
