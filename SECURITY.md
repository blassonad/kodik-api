# Security Policy

## Supported Versions

Исправления безопасности предоставляются для последней опубликованной minor-версии и для ветки, готовящей следующий релиз.

| Версия | Получает security fixes |
|---|---|
| Последняя опубликованная minor-версия | Да |
| `main` / ветка предстоящего релиза | Да |
| Более ранние minor-версии | Нет |

До первой публикации на crates.io исходная версия `0.1.0` в этой ветке считается поддерживаемой.

## Reporting a Vulnerability

Не создавайте публичный issue и не публикуйте proof of concept для подозреваемой уязвимости. Вместо этого создайте [private security advisory](https://github.com/blassonad/kodik-api/security/advisories/new) в репозитории. В сообщении укажите затронутую версию, шаги воспроизведения, ожидаемое и фактическое поведение, возможное влияние и, если есть, предложение по исправлению.

Maintainer подтвердит получение отчёта в течение **7 календарных дней** и сообщит о ходе обработки. После подтверждения проблемы будет подготовлено исправление, тест на регрессию, запись в changelog и согласованный с исследователем способ публичного раскрытия. Не включайте в отчёт действующие токены или иные секреты; при случайном раскрытии немедленно отзовите их у соответствующего поставщика.

## Scope

К scope относятся исходный код библиотеки, workflow-файлы GitHub Actions, процесс packaging и опубликованный crate. Сторонние сервисы Kodik и crates.io не входят в scope этого репозитория, но проблемы с некорректной обработкой их ответов можно сообщать по описанному процессу.
